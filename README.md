# MY LINUX LEARNING DAY-1
Today i have learned basic Linux commands for AWS Solution Architect.
1. pwd-this tell the recent working folder of yours.
2. mkdir[name]-this help to make a new folder.
3. cd[name]-this help you to move from one folder to another.
4. ls-give a list of files and sub-folder of working folder.
5. touch[file name]-this helps to create a new empty file.
6. cp[source][destination]-this command helps you to copy a file from a folder and paste  it into another folder.
7. mv[source][destination]-this command helps you to move a file from one folder to another and rename it also.
8. rm[file name]-this helps you to permanently delete a file.
